# 📊 Employee Performance Analytics Dashboard

An interactive **Employee Performance Analytics Dashboard** developed using **Microsoft Power BI** to transform operational employee data into clear, actionable insights for performance monitoring and data-driven decision-making.

## 🖥️ Dashboard Preview

<img width="700" height="369" alt="image" src="https://github.com/user-attachments/assets/78160316-f44d-405a-aada-e7ddc4f13c6f" />

The dashboard consists of two main analytical views:

- **Performance Overview** – Provides a high-level view of sales, target achievement, employee performance, working hours, overtime, and key performance indicators.
- **Attendance & Operations** – Provides detailed analysis of employee attendance, absences, lateness, leave, shifts, working hours, and operational records.

## 🎯 Key Features

- Sales performance and target achievement analysis
- Employee performance monitoring
- Attendance, absence, and lateness tracking
- Working hours and overtime analysis
- Average invoice analysis
- Sales analysis by employee
- Sales analysis by site
- Daily and monthly performance trends
- Employee KPI monitoring
- Interactive filtering by employee, month, date, and site
- Detailed attendance and operational records

## 📈 Key Performance Indicators

The dashboard tracks several important KPIs, including:

- Total Sales
- Target Achievement %
- Average Invoice Value
- Total Employees
- Total Working Hours
- Overtime Hours
- Employee Performance Score
- Attendance Metrics
- Absence Metrics
- Lateness Metrics
- Site Performance
- Employee Sales Performance

## 🔄 Project Workflow

**Data Collection → Data Cleaning → Power Query Transformation → Data Modeling → DAX Calculations → KPI Development → Dashboard Design → Interactive Analysis**

## 💡 Project Objective

The objective of this project is to provide a centralized analytical view of employee performance and operational data, enabling users to monitor key performance indicators, identify trends, compare employee and site performance, and support data-driven decision-making.

## 🔐 Data Privacy

The original dataset and Power BI source files are not publicly available because they contain private operational information.

The dashboard preview is provided for **portfolio and demonstration purposes only**.
